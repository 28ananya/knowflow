# KnowFlow v1

## Overview

KnowFlow v1 is the initial working foundation of the application. The project now includes a working backend API, a React frontend shell, auth flow scaffolding, and a small automated test suite to validate the core behavior.

## Implemented in v1

### Backend

- FastAPI application factory in `backend/app/main.py`
- Health check endpoint
- JWT-based authentication helpers and password hashing
- Register flow
- Login flow
- Current-user fetch route
- CORS configuration for local frontend development (`http://localhost:5173`)
- Smoke tests for health and auth behavior

### Frontend

- Vite + React + TypeScript app foundation
- App routing shell
- Login page UI
- Auth API integration layer
- Local token handling for the initial auth flow

### Project structure

- `backend/` contains the API, core services, auth logic, and tests
- `frontend/` contains the React application and Vite config
- `docs/` contains product and engineering documentation
- `infrastructure/` contains Docker-based deployment scaffolding

## Current constraints

- Auth is intentionally in-memory rather than persisted to a database
- There is no database-backed user model yet
- No document ingestion or vector-search features are implemented yet
- The app is currently a foundation for the next production milestones
