# KnowFlow Frontend

React frontend scaffold for KnowFlow.

## Intended Structure

```text
frontend/
  src/
    api/          Backend API clients and query functions
    assets/       Static assets
    components/   Reusable UI components
    hooks/        React hooks
    lib/          Shared frontend utilities
    routes/       Route-level screens and layouts
```

## Current Status

Scaffold only. No UI, routing, authentication, or data fetching has been implemented yet.
